## Colour

The HDPE look reads the constant primvar `primvars:displayColor` authored on `/CrateDeep325/Geo` (inherited by all HDPE meshes; the shader's `UsdPrimvarReader_float3` fallback is the same blue). To switch, set it in the scene:

```python
UsdGeom.PrimvarsAPI(stage.GetPrimAtPath('<crate>/Geo')).GetPrimvar('displayColor').Set([(r, g, b)])
```

## Notes

- Used on the angled sort rack with the open top (+Z in the asset frame) facing the robot; the scene applies the tilt, the asset stays upright.
- Usable height 284 mm is modelled as a 41 mm solid base collider so the interior matches the catalogue; the visual base is a plate on support ribs.
- `PhysxSchema` is not in usd-core, so `PhysxCollisionAPI` is added as an applied-schema token with raw `physxCollision:contactOffset`/`restOffset` attributes; Isaac Sim reads them natively.
- Mass is spread by PhysX over the collider boxes (no explicit inertia).
