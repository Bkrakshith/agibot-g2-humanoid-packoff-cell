## Colour

The HDPE look reads the constant primvar `primvars:displayColor` authored on `/CrateBaleArm199/Geo` (inherited by all HDPE meshes; the shader's `UsdPrimvarReader_float3` fallback is the same blue). To switch, set it in the scene:

```python
UsdGeom.PrimvarsAPI(stage.GetPrimAtPath('<crate>/Geo')).GetPrimvar('displayColor').Set([(r, g, b)])
```

## Notes

- Real bale-arm crates taper for nesting; modelled with straight walls at the estimated inner size.
- Bale arms (8 mm zinc wire, U-shaped) are visual only, lying folded on the rim of the long sides with the crossbar across the opening; they sink 4 mm into a rim groove so they do not raise the 199 mm height. Prims: Geo/BaleArmNegY, Geo/BaleArmPosY. No collision (add one if stacking on arms is ever simulated).
- `PhysxSchema` is not in usd-core, so `PhysxCollisionAPI` is added as an applied-schema token with raw `physxCollision:contactOffset`/`restOffset` attributes; Isaac Sim reads them natively.
- Mass is spread by PhysX over the collider boxes (no explicit inertia).
