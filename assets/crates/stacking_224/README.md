## Prim paths

- `/CrateStacking224`: rigid body root (origin = centre of base footprint, Z=0, long side +Y)
- `/CrateStacking224/Geo/{Base,Walls,Ribs,Rim}`: visual meshes (HDPE look)
- `/CrateStacking224/Colliders/*`: collider boxes (UsdGeom.Cube, purpose=guide)
- `/CrateStacking224/InteriorVolume`: invisible guide box = inner volume, no collision
- `/CrateStacking224/PhysicsMaterials/HDPE`: physics material (physics.usda)

## Colour

The HDPE look reads the constant primvar `primvars:displayColor` authored on `/CrateStacking224/Geo` (inherited by all HDPE meshes; the shader's `UsdPrimvarReader_float3` fallback is the same blue). To switch, set it in the scene:

```python
UsdGeom.PrimvarsAPI(stage.GetPrimAtPath('<crate>/Geo')).GetPrimvar('displayColor').Set([(r, g, b)])
```

| black | (0.02, 0.02, 0.02) |

Stage 6 replaces the preview look with MDL; keep reading the same primvar.

## Notes

- Base perforation is a visual lattice of 8 mm square holes on a 16 mm pitch; the collider base is a solid slab (bags cannot fall through anyway).
- `PhysxSchema` is not in usd-core, so `PhysxCollisionAPI` is added as an applied-schema token with raw `physxCollision:contactOffset`/`restOffset` attributes; Isaac Sim reads them natively.
- Mass is spread by PhysX over the collider boxes (no explicit inertia).
